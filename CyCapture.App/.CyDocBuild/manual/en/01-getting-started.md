CyCapture is a tray-first capture tool. It stays in the Windows notification area and appears only when you need it.

## First capture {#first-capture}

1. Start CyCapture and keep the green CY icon in the [[Tray]].
2. Press **Print Screen** and choose a mode.
3. For visual modes, point at a smart target or choose Window, Screen or Free region.
4. Confirm the target. The completion notification opens the result for six seconds.

## Where files go {#files}

Captures are written to the folder shown in [Settings](doc:settings#common-settings). The default is the CyCapture folder under Pictures. Files can optionally be separated by type and by day.

```callout
{"type":"tip","title":"Stop a recording","body":"While Video, GIF or Audio is active, Print Screen always stops and finalizes the current recording."}
```
