CyCapture est un outil de capture piloté depuis le tray. Il reste dans la zone de notification Windows et apparaît uniquement lorsque vous en avez besoin.

## Première capture {#first-capture}

1. Démarrez CyCapture et conservez l’icône CY verte dans le [[Tray]].
2. Appuyez sur **Impr. écran** et choisissez un mode.
3. Pour un mode visuel, pointez une cible intelligente ou choisissez Fenêtre, Écran ou Zone libre.
4. Confirmez la cible. La notification de fin ouvre le résultat pendant six secondes.

## Emplacement des fichiers {#files}

Les captures sont écrites dans le dossier affiché dans les [Réglages](doc:settings#common-settings). Par défaut, il s’agit du dossier CyCapture dans Images. Les fichiers peuvent être séparés par type et par jour.

```callout

```
